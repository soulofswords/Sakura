# Sakura update — 22 October 2026

This release ships refreshed Sakura Companion and Sakura VTuber Windows installers, plus Sakura Mobile 0.3.20 (Android version code 26).

## Calendar scheduling

- Companion chat prepares Google Calendar events from natural-language requests after sign-in. Sakura asks for missing dates/times, reads back the title and time range, and waits for confirmation before saving.
- Event titles now exclude the surrounding spoken instruction. For example, “I have an interview, add that to the calendar” becomes “Interview.” Descriptive subjects such as “interview with Infosys” are retained.
- Save claims require confirmation from the Calendar API. Ambiguous failures advise checking Calendar before retrying to avoid duplicates.
- Mobile opens a draft in the phone's Calendar app for review and Save; it does not claim to have saved the event itself.

## Included application updates

- Integrated the approval-based Sakura Agent workspace into Companion, with Google sign-in and granted-scope Google Workspace actions.
- Updated PC tools/status, conversation grounding, Hindi handling, voice interruption, search approval, attachment summaries and speech-start latency.
- Updated 3D model presentation, clothing visibility controls, pose and gesture behavior, Companion/VTuber branding, Android full-screen controls, phone-local assistant, camera modes and optional wake phrase.
- Preserved the Companion source as a private repository. The public Sakura-Downloads repository contains release notes, checksums and compiled installers only.

## Validation

- The configured Windows split-release suite passed 359 Python tests, frontend and mobile checks, and both product-specific install/payload smoke tests.
- Android compilation, R8, APK signing, archive integrity, Java calendar behavior, and PC/Mobile event-title tests passed.
- Windows setup files are unsigned. The Android APK uses Sakura's existing local testing key. No new macOS image was built.
