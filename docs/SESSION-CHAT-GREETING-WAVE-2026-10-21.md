# Session-only chat and greeting wave — 21 October 2026

Production PC LLM instances now explicitly disable persistent memory. Conversation and its working summary stay in RAM for the current session. Startup ignores and removes the exact old conversation JSON/temp files and previously generated grounding backups. No chat is written to disk, so crashes/forced exits cannot restore a stale conversation on next launch. Shutdown clears in-memory conversation and screen notes; epoch guards prevent late summaries from restoring cleared data. The native Close action also clears UI/history when closing to the wake-listener tray. Settings, API credentials, models, expressions and bone fixes remain independently saved. Developer tests may explicitly use persistent memory paths, but production app constructs LLM(persist_memory=False).

Refresh-memory now reports session-only chat status; local product refresh no longer seeds conversation-memory.json from the source project. This limits carryover of mistakes across app sessions; it does not guarantee a generative model can never hallucinate during an active conversation.

Greeting-only messages such as hello/hi/hey request greeting_wave for capable PMX/VRM rigs. The frontend starts it on the first speech phrase playback; no automatic Reactions setting is required. Position-based right-arm IK raises the hand beside/above the head, opens the fingers and sweeps the wrist, then blends to neutral. Existing wave dance remains a separate routine. Tracking and Live2D are excluded from procedural 3D arm posing. Live2D needs an authored motion for an equivalent wave.

Validation: session reopen/no-disk-write/legacy-cleanup and pending-summary cancellation tests; local/cloud API greeting gating; finite pose/lifecycle tests; real Ringo PMX and a VRM waved during audio playback, wrist reached above shoulder, mouth moved and gesture completed. Screenshots/reports in audit-results/greeting-wave-*. Headless fixture audio used instead of microphone/cloud. Both local apps refreshed; restart needed. No installers or APK rebuilt.
