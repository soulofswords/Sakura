# Short command recognition and false shared history — 21 October 2026

User reported Delhi news transcribed as The Lineos, followed by a false claim of prior discussions. The installed app was running tiny Whisper on CPU and English microphone input used automatic language detection. A retained 1.38-second 16 kHz microphone WAV may correspond to the reported request; exact provenance cannot be proven from the overwrite-only filename. On that audio, tiny/no hints produced Belly News with low confidence; base/no hints produced Delinius. Base with short assistant/place vocabulary hints produced Delhi News in approximately 0.5 seconds. Medium was slower and unnecessary for this sample. Original WAV was read only for the audit; no live mic/camera was used.

Default STT changed from tiny to multilingual base. Microphone English is explicitly English; Hindi/Hinglish stays Hindi, while system audio callers retain auto. Deterministic decoding and a compact vocabulary covering common places and assistant commands improve names without replacing arbitrary text. Uncertain short fragments and repetitive decoding are rejected so the existing UI requests repetition. No Lineos-to-Delhi hard-coded rewrite. Silence/energy/VAD guards retained. Uploaded mic temporary files now have per-request unique names and are removed after use to prevent cross-client overwrite races and retention.

Added a shared-history response guard: claims such as we have been discussing require supporting prior user text; a short repeated unclear fragment alone is insufficient evidence. Invalid drafts are retried once; repeated failure returns a brief clarification and never saves the false claim. Same local/cloud chat path. This heuristic does not guarantee detection of every invented memory, nor perfect transcription.

Validation: actual revised STT pipeline produced Delhi News on retained audio; unit tests for explicit language, hints, silence and confidence rejection; false shared-history, genuine prior context, fiction and retry/fallback tests plus personality/session/conversation regressions. Local PC products refreshed; restart required to replace the loaded tiny STT instance. No installer/APK/GitHub changes.
