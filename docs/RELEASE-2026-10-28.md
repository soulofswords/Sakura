# Sakura 1.0.0 — Windows release

## Downloads

Choose Sakura Companion for conversation, local/cloud AI, Agent workflows and optional VTuber tracking. Choose Sakura VTuber for standalone tracking and streaming, without the companion language model. Install them into separate folders.

## Universal local AI

In Companion, open Settings → AI & LLM. Select Qwen3-VL 4B for the lighter vision-capable option, or use the Qwen 3.6 · Colibri shortcut when that model is registered. Click Save AI settings to apply. The model download is separate from the installer.

Qwen 3.6 is intended for more demanding text tasks and has substantially higher resource requirements. Reference PC: RTX 3080 with 12 GB VRAM. Budget around 10 GB VRAM and 24 GB system RAM, with 32 GB RAM recommended. These are estimates, not a reproducible comparative benchmark. Quantization, context, avatar and other applications affect actual usage and response quality. Screen/camera inputs continue to use a separate vision model. Game Mode retains its own model selection.

## Agent skills

All 15 Sakura starter procedures are installed on a fresh Companion installation. Open Agent mode → Skills. They guide the selected model; they do not supply missing services, replace a capable model, or grant permission to execute actions. Third-party services/hardware must be configured separately.

## Sakura Mobile 0.3.31 (Android)

The APK is separate from the Windows installers and pairs with either edition. Android 9 or newer with a current Android System WebView.

- Discover every Sakura PC on your home network by its stable name and switch between them, instead of typing an address that changes.
- Pair over HTTPS with the PC certificate pinned. The phone refuses when the fingerprint differs from the one the PC displays; manual pairing by code and fingerprint is still available.
- The avatar renderer runs in its own frame with a separate origin and no access to Sakura's privileged bridge.
- Signed with Sakura's local testing key, not a store release key. If that key ever changes, uninstall the old app first.

Phone camera and home-network behaviour still need a physical-device test; the automated checks cover the pairing logic, TLS pinning and archive contents.
