# Maintaining the Sakura user guides

The editable sources are companion.md and vtuber.md in this folder. The HTML and PDFs are generated by tools/build-user-guides.py, run from the repository root with Python containing ReportLab and pypdf.

After the UI update:
1. Check the real button names, menu locations and edition guards in static/index.html, static/js/app.js and the relevant feature module. Installed editions can differ from source; verify the shipped build too.
2. Update the numbered instructions and success checks in the Markdown files. Keep Companion AI and standalone VTuber workflows separate.
3. Update the snapshot date in both source headers and the generator. Update its expected chapter counts if chapters are added/removed.
4. Rebuild the outputs, render every PDF page, inspect layout, and validate links before distribution. Follow the PDF authoring skill's artifact-operation marker when using that skill.
5. Deliver the matching HTML/PDF set together. The current build also copies them beside the user's launchers in F:/AI/assistant and updates the old combined guide to an edition chooser.
