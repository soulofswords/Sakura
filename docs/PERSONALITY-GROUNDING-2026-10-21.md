# Grounded personality and memory — 21 October 2026

The reported invented Agent V history had persisted in assistant turns and a 1,416-character first-person summary. That summary was promoted as factual conversation memory, reinforcing later inventions.

Added shared persona-grounding rules to the full personality, normal generation, compact-context identity and retry path. The assistant remains warm but must not claim offscreen friends, employment, possessions or an independent biography. Current identity questions use the configured assistant/stage name and AI role rather than creative generation. Detected invented biographies are excluded from outgoing history; follow-ups explicitly referring to an excluded acquaintance receive an honest correction. Directly requested stories remain allowed and retained as fictional context. A conservative response check retries known invented-biography/evasive/overlong-smalltalk patterns once; it cannot guarantee detection of all possible hallucinations.

Memory archives are retained. If a saved summary contains first-person assistant narration or detected invented biography, startup preserves the original memory file as a dated .bak, discards only the unreliable working summary, and restarts summary coverage. Future summaries use user-authored turns, with instructions distinguishing user statements from questions/assumptions. Bad assistant text is retained in the archive but filtered out of future prompts. This does not delete saved chat or manually alter files used by an already-running process.
