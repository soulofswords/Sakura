# Contributing to Sakura

1. Describe the concrete problem and resulting behaviour in a small issue or pull request.
2. Keep changes scoped. Companion includes Agent and VTuber modes; standalone VTuber must retain its tracking/chat-reader/voice-conversion boundary without starting Companion's chat/Agent LLM.
3. Use synthetic fixtures. Never commit settings, credentials, account tokens, conversations, voice recordings, weights or assets you cannot redistribute.
4. Run relevant Python and UI/browser checks. Check light/dark appearance and narrow windows for affected UI. Report hardware/provider/platform checks you could not perform.
5. Include meaningful regression coverage for behavioural/security fixes and explain verification. Retain third-party notices.

Contributions to Sakura's original code use the project's GPL v3 terms and, for Live2D integration code, its documented optional permission. Only contribute material you have the right to license. Copyright in your contributions remains yours.
