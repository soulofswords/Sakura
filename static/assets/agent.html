Google account

Set up Google sign-in

Sakura needs a registered Google desktop app before account sign-in can work. This is a one-time developer setup. Your Gemini API key cannot connect your calendar.

  1. In Google Cloud, select your project and enable Google Calendar API.
  2. Configure the app audience in Google Auth Platform. If the app is in testing, add your Google account as a test user.
  3. In Google Auth Platform → Clients, create a Desktop app client and download its JSON file.

The file is read only when you select it. Client settings are saved using Sakura’s protected credential storage. Then use Sign in with Google below.

Connect your Google account for Calendar and optional Drive, Docs and Sheets tools.

Google will ask you to choose an account and approve Calendar access. Choose Calendar only, or include Drive, Docs and Sheets. File edits always require a separate review and approval. Gmail and other services are not included.

Workspace access requests broad Drive permission. Enable Drive, Docs and Sheets APIs in your Google Cloud project. Existing users must sign in again to grant added permissions.
